# SkillMap — Starter Project

SkillMap is a learning-roadmap dashboard prototype built with React and Vite.

## Requirements
- Node.js LTS (includes npm)
- Visual Studio Code or another code editor

## Run on Windows
1. Extract the ZIP.
2. Open the extracted `SkillMap` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:

   ```powershell
   npm install
   npm run dev
   ```

5. Open the local URL shown by Vite (usually `http://localhost:5173`).

## Build check
Run `npm run build` to create the production build in `dist/`.

## Current prototype status
- Responsive dashboard layout
- Sidebar navigation state
- Search/filter for sample learning roadmaps
- Sample statistics and progress bars

## Not implemented yet
- Real user registration/login and server-side authentication
- Database persistence
- Real roadmap lesson pages and completion tracking
- Production deployment
- Automated test suite

This is a starter prototype, not a production-secure application. Do not enter real passwords or sensitive personal information. The next development steps should add a backend, validated authentication, database storage, functional roadmap screens, and tests.
